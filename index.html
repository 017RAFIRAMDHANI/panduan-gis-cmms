Pengantar: satu data, dua pintu

Aplikasi ini punya dua pintu untuk data aset jaringan distribusi yang sama:

PintuBuka dari menuAlamatCocok untuk

Info
Keduanya membaca register yang sama. Aset yang dibuat di peta langsung ada di daftar Asset (T&D), dan aset yang dibuat di CMMS tampil di peta bila punya koordinat (Service Address) dan Is GIS tidak dimatikan. Perubahan dari CMMS bisa butuh sampai ±12 detik untuk tampil di peta (butir R-74).

Istilah yang dipakai di panduan ini

Service Address (SA)
Alamat + koordinat. Titik aset di peta dibaca dari SA-nya. Kode berbentuk SA000002431; pencarian juga menerima bentuk pendek SA2431.
Host
Aset/lokasi yang memikul atau berisi aset lain: tiang memikul alat hubung, gardu berisi trafo, kubikel, kabel inlet/outlet.
Isi
Aset yang menumpang pada host. Isi tiang TM (Recloser, LBS, ACOS, CO, DS) digambar di titik tiangnya dan dijajarkan kiri-kanan bila lebih dari satu (R-72).
Aset linear
Kabel/hantaran. Digambar dari tiang ke tiang; panah menunjukkan arah awal ke akhir.
Relasi
Ikatan antar aset di tab Relationships/Konektivitas: POLE (kabel melewati tiang), CONNECTFROM / CONNECTTO (kabel tersambung ke kabel lain di awal / di akhir).
Gawang
Bentang kabel antara dua tiang berurutan.
Segment · Section · Penyulang
Hierarki jaringan tegak: gawang → segment → section → penyulang (keputusan K16). Penyulang = satu MV Cell di Gardu Induk (K34).
Status aset
NOT_READY, DRAFT, OPERATING, DECOMMISSIONED, dll. Diubah lewat workflow CMMS.

Service Address (alamat layanan)

Setiap aset dan lokasi yang tampil di peta punya Service Address (SA). Titiknya di peta dibaca dari koordinat SA. Beberapa aset boleh berbagi satu SA (misalnya tiang dan alat di atasnya).

Mengisi Service Address

R-02R-29R-63R-67R-82

Di peta, SA diisi pada tab Service Address laci Create Asset (T&D) atau Create Location. Titik yang Anda klik menjadi Latitude/Longitude, dan wilayah (provinsi, kota, kecamatan) terisi otomatis dari titik itu.

Memakai SA yang sudah ada (Choose, R-67)

  1. Pada tab Service Address, klik Choose.
  2. Cari kode atau deskripsi SA, lalu pilih barisnya.
  3. Titik aset mengikuti koordinat SA itu. SA di luar wilayah site ditolak: "Service Address terpilih di luar wilayah site Anda; pilih Service Address lain atau tekan Reset."
Perhatian
Di laci Edit, tombol Choose/Reset tidak langsung mengganti alamat: muncul dialog "Lanjut ke Pindahkan?", karena mengganti SA sama dengan memindah titik (Bab 12).

Di CMMS, master SA dikelola di Master Data → Service Address (/master/service-address). Tab Service Address di borang Asset (T&D) dan Locations memakai kolom yang sama dengan borang peta, tetapi koordinat diketik sendiri.

  1. Buka Master Data → Service Address, klik tombol tambah.
  2. Isi Address Description dan Formatted Address (keduanya wajib walau tanpa tanda *).
  3. Isi Latitude/Longitude dan wilayah. Di halaman ini wilayah tidak terisi otomatis.
  4. Klik Submit. Berhasil: "Submitted!" / "Your data has been submitted."

Penanda (Tandai tempat)

Penanda menandai tempat calon aset sebelum datanya lengkap. Isinya hanya alamat (SA) + nama. Nama penanda = Address Description.

Membuat penanda

F-144Creator
  1. Toolbar → ikon pin dengan titik di tengah (Tandai tempat). Muncul panel "Tandai tempat" / "Klik peta untuk menandai tempat."
  2. Klik tempat kosong di peta. Laci Create Marker terbuka.
  3. Isi Address Description (jadi nama penanda) dan Formatted Address. Koordinat, zona waktu (WIB/WITA/WIT dari bujur), negara, dan wilayah sudah terisi.
  4. Klik Save & Create Marker. Berhasil: toast "Penanda tersimpan." dan pin biru muncul.
Kalau gagal
Kosongkan Formatted Address lalu Save → ditolak "Formatted address is required". Esc/Cancel → "Batalkan pengisian?" dengan pilihan Lanjut mengisi / Ya, batalkan.

CMMS tidak punya penanda. Padanannya adalah membuat Service Address saja di Master Data → Service Address (Bab 3); alamat itu bisa dipilih lewat Choose saat membuat aset.

Popup penanda: Jadikan aset, Edit, Geser, Hapus

R-62

Dengan alat Pilih, klik pin penanda. Popup berisi nama, Kode alamat, Dibuat oleh, dan tombol aksi.

Geser penanda (R-62)

  1. Klik Geser penanda. Panel Geser penanda menampilkan Titik sekarang dan Titik baru ("—").
  2. Seret pin, atau klik titik baru di peta. Titik baru terisi. (Melepas seretan belum menyimpan.)
  3. Klik Simpan → "Penanda dipindahkan" / "Titik baru penanda tersimpan." Pin pindah tanpa muat ulang. Bila pindah kecamatan, wilayah alamat ikut berganti.
  4. Batal membatalkan tanpa menyimpan.

Edit penanda

Membuka laci Edit Marker (kolom sama dengan Create Marker). Save → "Penanda diperbarui" / "Alamat dan nama penanda tersimpan." Isian langsung segar bila dibuka lagi (perbaikan 7 Okt).

Jadikan aset

  1. Klik Jadikan aset. Muncul dialog Pilih kelas lokasi atau aset.
  2. Pilih kelas lokasi (mis. Gardu Distribusi) → laci Create Location; atau kelas aset (mis. Tiang TM) → laci Create Asset. SA penanda dipakai ulang.
  3. Sesudah aset/lokasi tersimpan, penanda hilang dan SA-nya menjadi alamat benda baru.

Hapus penanda

Tombol Hapus penanda hanya muncul untuk admin/superadmin (atau izin d:gis). Konfirmasi "Hapus penanda ini?" → Ya, hapus. Penanda dan SA-nya ikut terhapus.

Tidak ada padanan. Alamat penanda bisa dilihat di Master Data → Service Address dengan mencari Kode alamat-nya; koordinatnya sama dengan pin (R-74).

Location (gardu, GI, KIT, SPKLU)

Location adalah wadah: Gardu Induk (FGK01001), KIT 20 kV (FGK03001), Gardu Distribusi (GDD01001/GDD01002), Gardu KIT TR (GDD01003), Gardu Hubung (GDD02001), SPKLU (PBD10001). Isi lokasi (trafo, kubikel, MV Cell, LV cable) dibuat dari tab Isi (Bab 7).

Membuat lokasi

CreatorF-53R-32
  1. Toolbar → Buat lokasi. Panel: "Buat lokasi" / "Klik peta pada titik yang dituju."
  2. Klik titik di peta (harus di dalam wilayah site Anda).
  3. Dialog Pilih kelas lokasi: pilih jenis, mis. GDD01001 Gardu Distribusi.
  4. Laci Create Location terbuka dengan koordinat titik klik. Isi kolom wajib (lihat kamus di bawah) di setiap tab.
  5. Klik Save → "Confirm Save" / "Are you sure you want to create this location?" → Yes, Save.
  6. Berhasil: "Success" / "Location created successfully!"
Perhatian
Gardu Hubung dan Gardu Distribusi wajib punya Penyulang. Penyulang dipilih dari lokasi penyulang berstatus OPERATING.
  1. Buka Assets → Locations, klik tombol tambah lokasi.
  2. Pilih Classification (pohon LOCATION). Nomor Lokasi terbit otomatis.
  3. Isi kolom wajib di kartu Location, lalu isi kartu Service Address (koordinat diketik, atau Choose).
  4. Klik Save → "Save Location?". Berhasil: dialog "Draft saved!" (Stay Here / Exit).
  5. Lokasi berstatus draft/NOT_READY; perubahan status lewat tombol Submit (workflow).

Perbedaan halaman CMMS: section tampil sebagai kartu bertumpuk (bukan tab), Is GIS bawaannya mati, dan ada More Actions: View Drilldown, View History, Change Status, View/Modify Parent, Associate Systems, Delete Form.

2. Tiga kata kunci relasi

POLE
“Kabel ini menempel di tiang ini.” Satu baris untuk setiap tiang yang diklik. Target = tiang. Tidak berarti tersambung ke kabel lain di tiang itu.
CONNECTFROM
“Kabel ini berasal / bercabang dari aset itu.” Dipakai untuk sambungan di awal kabel (ke kabel lain atau ke sel MV Cell). Juga dipakai di akhir kabel bila kabel tujuan hanya lewat di tiang itu (dicabang, R-19).
CONNECTTO
“Kabel ini berakhir / masuk ke aset itu.” Dipakai untuk sambungan di akhir ke kabel lain yang berujung di tiang itu, dan untuk kabel yang masuk ke alat (LBS, recloser) di tiang.
Sequence
Nomor urut baris = urutan sepanjang kabel. Nomor kecil = dekat awal.
Source Start/End Measure
Posisi titik itu di kabel ini, dalam km dari awal kabel. Dihitung otomatis dari jarak di peta (3 desimal). Start = End karena titiknya satu.
Target Start/End Measure
Posisi titik itu di aset tujuan. Tiang dan alat = 0. Bila tujuannya kabel lain, isinya km titik sambung pada kabel itu.
Panjang di peta / End Measure
Panjang di peta dihitung otomatis dan tampil di kepala laci. End Measure adalah panjang resmi kabel yang diketik sendiri, harus ≥ panjang di peta.
Posisi km tiap titik (Source Measure) — angka asli data TUTOR Kabel A : T1 (0) ──► T2 (0,056) ──► T3 (0,111) Kabel B : [dari A km 0,056] T2 (0) ──► T4 (0,056) Kabel C : [dari A km 0,111] T3 (0) ──► T5 (0,056) ──► T4 (0,111) [ke B km 0,056] Kabel D : [dari Sel 1] GI ──► T1 (0,089) [masuk LBS 1] Kabel E : [dari Sel 1] GI ──► T6 (0,111)[LBS 6] ──► T7 (0,167) ──► T8 (0,222)[Recloser 8] ──► T9 (0,278)
